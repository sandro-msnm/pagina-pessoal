# Ativide Prática - Página Pessoal com Flexbox e Grid Layout

Repositório criado para a entrega da atividade avaliativa da disciplina de **Programação Web I**, do curso **Técnico em Informática para Internet** (IF Sudeste MG - Campus Barbacena).

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estruturação semântica da página pessoal.
* **CSS3 (Grid Layout):** Utilizado para o alinhamento global da página (`header`, `nav`, `main`, `footer`) e para a distribuição dos cartões em linhas e colunas simétricas.
* **CSS3 (Flexbox):** Utilizado para a organização e alinhamento interno dos elementos dos cartões e das tags de tecnologia.

## 📋 Requisitos Atendidos
1. **Seção de Apresentação:** Criação da área "Tecnologias e Interesses" contendo 4 cartões explicativos.
2. **Grid Layout nos Cartões:** Organização estruturada em colunas e aplicação da propriedade `gap` para espaçamento responsivo.
3. **Flexbox Interno:** Organização em colunas e uso de propriedades de alinhamento (`flex-direction`, `justify-content`) nos itens dos cartões.
4. **Estrutura Global com Grid:** Uso das propriedades `grid-column` e `grid-row` para mesclar colunas e delimitar os espaços do cabeçalho, menu lateral, conteúdo principal e rodapé.
5. **Boas Práticas:** Código HTML e CSS limpos, devidamente indentados e folha de estilos mantida de forma externa (`style.css`).
